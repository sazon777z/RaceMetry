# DRAGon — Профессиональный прибор телеметрии на ESP32-S3

Автономный автомобильный измеритель динамики разгона, торможения и дистанций (высокоточный аналог Dragy, RaceLogic PerformanceBox, RaceBox).

---

## ⚡ Особенности и точность
- **Спутниковая навигация 10–18 Гц**: Прямая работа с u-blox M10Q по скоростному бинарному протоколу **UBX-NAV-PVT** на скорости 460800 бод.
- **Doppler Velocity**: Измерение скорости по доплеровскому сдвигу частоты спутникового сигнала (погрешность скорости < 0.05 м/с или 0.18 км/ч).
- **Launch Jerk Trigger (< 1 мс)**: Мгновенное детектирование старта по акселерометру MPU-9250 на частоте 200 Гц (полностью исключает 50–100 мс задержку первого GPS пакета).
- **Эрмитова кубическая и квадратичная интерполяция**: Расчет времени пересечения отметок (0-100, 100-200, 402 м) с субмиллисекундной точностью.
- **1-Foot Rollout (стандарт Dragy / NHRA)**: Поддержка замера с раскатом 1 фут (30.48 см) или честного физического 0-100.
- **Контроль уклона (Slope Check)**: Анализ перепада геодезических высот за заезд. Если уклон превышает -1.0%, заезд помечается как `INVALID SLOPE`.
- **Двухъядерная многозадачность FreeRTOS**:
  - **Ядро 0**: Высокоприоритетный опрос датчиков (200 Гц IMU, UBX GPS DMA, математика заезда).
  - **Ядро 1**: 40-60 FPS UI на 1.47" IPS дисплее (ST7789), светодиод WS2812B, кнопки, сохранение в NVS.

## 🔌 Схема подключения (ESP32-S3 Super Mini)

| Модуль | Вывод модуля | Пин ESP32-S3 | Примечание |
| :--- | :--- | :--- | :--- |
| **IPS Дисплей 1.47" ST7789** | SCL | `GPIO 1` | SPI Clock (SCLK) |
| | SDA | `GPIO 2` | SPI Data (MOSI) |
| | RST | `GPIO 3` | Reset |
| | DC | `GPIO 4` | Data / Command |
| | CS | `GPIO 5` | Chip Select |
| | IPL / BLK | `GPIO 6` | Подсветка (PWM) |
| | VDD / GND | `3.3V / GND` | Питание дисплея |
| **GPS u-blox M10Q** | TX | `RX (GPIO 44)` | RX ESP32 (Hardware Serial1) |
| | RX | `TX (GPIO 43)` | TX ESP32 (Команды UBX) |
| | VCC / GND | `3.3V / 5V` | Питание GPS |
| **IMU MPU-9250** | SCL | `GPIO 12` | I2C Clock |
| | SDA | `GPIO 13` | I2C Data (400 кГц) |
| | VCC / GND | `3.3V / GND` | Питание датчика (AD0 к GND) |
| **WS2812B RGB LED** | DIN | `GPIO 11` | RMT управление |
| **Кнопка 1 (Left / Mode)** | Pin | `GPIO 7` | Вторая ножка к `GND` (INPUT_PULLUP) |
| **Кнопка 2 (Right / Action)** | Pin | `GPIO 8` | Вторая ножка к `GND` (INPUT_PULLUP) |

> ℹ️ *Все пины легко переназначаются в файле `Config.h`.*

## 🛠️ Настройка Arduino IDE

### 1. Установка плат ESP32:
1. Откройте **Файл -> Настройки**.
2. В поле *Дополнительные ссылки для Менеджера плат* добавьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. Откройте **Инструменты -> Плата -> Менеджер плат**, найдите `esp32` (by Espressif Systems) и установите версию 2.0.x или 3.x.

### 2. Установка библиотек:
Откройте **Скетч -> Подключить библиотеку -> Управлять библиотеками...** и установите:
- **LovyanGFX** (by lovyan03) — быстрая библиотека для ST7789 с поддержкой DMA спрайтов.

### 3. Параметры компиляции в меню "Инструменты":
- **Board**: `ESP32S3 Dev Module` (или `ESP32-S3 Super Mini`)
- **USB CDC On Boot**: `Enabled`
- **Flash Size**: `4MB` (или `8MB` в зависимости от модуля)
- **Partition Scheme**: `Default 4MB with spiffs`
- **PSRAM**: `Disabled` (или `QSPI/OPI` если распаяна)
- **Upload Speed**: `921600`

## 🎮 Управление и экраны

### Экраны:
1. **DASHBOARD LIVE**: Огромный цифровой спидометр (км/ч), статус спутников, live $G_{long}$ и пиковая перегрузка.
2. **DRAG RACE**: Гоночный таймер заезда, живой прогресс и список закрытых отсечек (0-60, 0-100, 100-200, 1/4 мили).
3. **BRAKE TEST**: Замер торможения (100 - 0 км/ч) с расчетом дистанции торможения в метрах.
4. **G-METER (G-Bowl)**: Аналоговый круг перегрузок с отображением продольных и поперечных сил в поворотах.
5. **RUN RESULTS**: Сводка завершенного заезда со статусом валидности уклона (зеленый/красный бейдж Dragy).
6. **GPS INFO**: Детальные метрики u-blox M10Q (координаты, точность в метрах, частота UBX).
7. **SETTINGS**: Включение/отключение 1-Foot Rollout, калибровка нуля IMU.

### Назначение кнопок:
- **Кнопка 1 (Левая)**:
  - *Короткое нажатие*: Переключение между экранами.
  - *Длинное нажатие*: Смена гоночной дисциплины.
- **Кнопка 2 (Правая)**:
  - *Короткое нажатие*: Взведение / сброс заезда (или переключение опции в Настройках).
  - *Длинное нажатие*: Калибровка нуля акселерометра (на ровной неподвижной машине).

## 🚦 Светодиодная индикация (WS2812B)
- 🔴 **Плавное красное дыхание**: Поиск спутников GPS / Фикс недостаточно точен.
- 🟢 **Постоянный зеленый**: **ARMED** (Прибор взведен, авто стоит неподвижно — жмите газ!).
- 🔵 **Пульсирующий циан**: Идет активный замер разгона.
- ❇️ **Тройная зеленая вспышка**: Заезд успешно завершен (уклон валиден).
- 🔶 **Тройная оранжевая вспышка**: Заезд завершен, но уклон превысил норму (> -1.0%).
- 🟣 **Фиолетовый**: Идет калибровка горизонта IMU.

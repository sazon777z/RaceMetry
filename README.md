# RaceMetry Pro — Профессиональный прибор телеметрии на ESP32-S3 (Bluetooth BLE / 20 Hz)

Автономный высокоточный автомобильный измеритель динамики разгона, торможения и дистанций (профессиональный аналог Dragy, RaceLogic PerformanceBox, RaceBox).

---

## ⚡ Особенности и архитектура

- **Устранение радиопомех на GPS**: Полное отсутствие дисплея исключает высокочастотные электромагнитные наводки SPI-шины и ШИМ-подсветки в диапазоне L1 GNSS. Приемник u-blox M10Q мгновенно ловит спутники даже внутри автомобиля.
- **Спутниковая навигация 20 Гц**: Прямая работа с u-blox M10Q по скоростному бинарному протоколу **UBX-NAV-PVT** на скорости 460800 бод с частотой 20 Гц (каждые 50 мс).
- **Doppler Velocity**: Высокоточное измерение скорости по доплеровскому сдвигу частоты спутникового сигнала (погрешность скорости < 0.05 м/с или 0.18 км/ч).
- **Launch Jerk Trigger (< 1 мс)**: Мгновенное детектирование старта по акселерометру MPU-9250 на частоте 200 Гц (полностью исключает 50–100 мс задержку первого GPS пакета).
- **Эрмитова кубическая и квадратичная интерполяция**: Расчет времени пересечения отметок (0-100, 100-200, 402 м) с субмиллисекундной точностью.
- **1-Foot Rollout (стандарт Dragy / NHRA)**: Поддержка замера с раскатом 1 фут (30.48 см) или честного физического 0-100.
- **Контроль уклона (Slope Check)**: Анализ перепада геодезических высот за заезд. Если уклон превышает -1.0%, заезд помечается как `INVALID SLOPE`.
- **Bluetooth Low Energy 5.0 (Nordic UART Service)**:
  - Прямое подключение к смартфону без разрыва мобильного интернета 4G/5G (в отличие от Wi-Fi).
  - Потоковая передача телеметрии 15 Гц.
- **Современное мобильное веб-приложение (PWA / Web Bluetooth)**:
  - Работает в Google Chrome / Edge на Android/ПК/Mac и через Bluefy / WebBLE на iOS прямо из браузера.
  - Живой цифровой спидометр HUD, 2D G-Meter, Drag Tree, динамические отсечки, Dragy-карточка с валидацией уклона, интерактивные графики разгона, база рекордов и голосовой помощник.

## 🔌 Схема подключения (ESP32-S3 + Модуль питания MH-CD42)

Вся силовая коммутация, зарядка аккумулятора и стабилизация напряжения вынесены на специализированный модуль **MH-CD42 (5V Boost + Li-Ion Charger)**. Это полностью исключает выгорание защитных диодов на плате ESP32 и обеспечивает чистое питание 5.0V для всей периферии.

### Таблица соединений:

| Модуль / Узел | Вывод модуля | Куда подключается | Назначение / Примечание |
| :--- | :--- | :--- | :--- |
| **Питание MH-CD42** | `VIN / GND` | Вход USB Type-C | Подключение зарядного устройства 5V |
| | `BAT +` | `BAT +` аккумулятора 3.7V | Плюс Li-Ion / Li-Po (3.0V – 4.2V) |
| | `BAT -` | `BAT -` аккумулятора / `GND` | Минус аккумулятора |
| | `OUT 5V` | `5V (VIN)` ESP32, `VCC` GPS, `VDD` WS2812B | Общая стабилизированная шина 5.0V |
| | `GND` | `GND` ESP32, `GND` GPS, `GND` IMU, `GND` LED | Общая земля всей схемы |
| | `KEY` | Кнопка на корпусе (к `GND`) | 1 клик — Вкл 5V, 2 клика — полное обесточивание |
| **Делитель АКБ** | Верхнее плечо ($R_1 = 220\text{k}$) | `BAT +` на плате MH-CD42 | Замер реального напряжения аккумулятора |
| | Нижнее плечо ($R_2 = 220\text{k}$) | Общий `GND` | Нижнее плечо делителя 1:2 |
| | Средняя точка ($R_1 / R_2$) | `GPIO 1` ESP32-S3 *(АЦП)* | Вход АЦП для расчета % заряда в Web App |
| **GPS u-blox M10Q** | `TX` | `RX (GPIO 44)` ESP32-S3 | Прием скоростных бинарных пакетов UBX 20 Гц |
| | `RX` | `TX (GPIO 43)` ESP32-S3 | Отправка конфигурационных команд в GPS |
| | `VCC / GND` | `5V (OUT)` MH-CD42 / `GND` | Питание приемника M10Q со встроенным LDO |
| **IMU MPU-9250** | `SCL` | `GPIO 13` ESP32-S3 | Шина I2C Clock (400 кГц) |
| | `SDA` | `GPIO 12` ESP32-S3 | Шина I2C Data (400 кГц) |
| | `VCC / GND` | `3.3V` ESP32-S3 / `GND` | Питание датчика (вывод AD0 подключен к GND) |
| **RGB LED WS2812B** | `DIN` | `GPIO 10` ESP32-S3 | Управление внешним адресным светодиодом |
| | `VDD / GND` | `5V (OUT)` MH-CD42 / `GND` | Питание светодиода |
| **Кнопка (опция)** | Контакт кнопки | `GPIO 11` ESP32-S3 (к `GND`) | Для вызова статуса АКБ (2 клика) или Deep Sleep |

> ℹ️ **Управление питанием через модуль MH-CD42:**
> - **Включение прибора**: Одно короткое нажатие на кнопку (подключенную к `KEY` на MH-CD42) активирует повышающий преобразователь 5V, и система мгновенно стартует.
> - **Выключение прибора**: Двойное быстрое нажатие на кнопку отключает шину 5V (прибор полностью обесточен, ток утечки 0 мкА).
> - **Индикация заряда на модуле**: 4 встроенных светодиода на плате MH-CD42 наглядно показывают текущий уровень аккумулятора (25% / 50% / 75% / 100%).

## 🛠️ Настройка Arduino IDE

### 1. Установка плат ESP32:
1. Откройте **Файл -> Настройки**.
2. В поле *Дополнительные ссылки для Менеджера плат* добавьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. Откройте **Инструменты -> Плата -> Менеджер плат**, найдите `esp32` (by Espressif Systems) и установите версию 2.0.x или 3.x.

### 2. Сторонние библиотеки:
**Не требуются!** Скетч использует только стандартные библиотеки ядра ESP32 (`BLEDevice`, `Preferences`, `Wire`, `HardwareSerial`).

### 3. Параметры компиляции в меню "Инструменты":
- **Board**: `ESP32S3 Dev Module` (или `ESP32-S3 Super Mini`)
- **USB CDC On Boot**: `Enabled`
- **Flash Size**: `4MB` (или `8MB` в зависимости от модуля)
- **Partition Scheme**: `Default 4MB with spiffs`
- **PSRAM**: `Disabled` (или `QSPI/OPI` если распаяна)
- **Upload Speed**: `921600`

## 📱 Использование веб-приложения RaceMetry Pro

1. Откройте файл `index.html` (или `dragon_app.html`) в браузере:
   - **Android**: Google Chrome, Edge, Brave, Samsung Internet.
   - **iOS (iPhone/iPad)**: Бесплатный браузер **Bluefy** или **WebBLE** из App Store (так как мобильный Safari на iOS блокирует Web Bluetooth).
   - **ПК / Ноутбук**: Google Chrome / Edge.
2. Включите Bluetooth на смартфоне и нажмите кнопку **«Подключить BLE»** в приложении.
3. Выберите из списка найденных устройств **`RaceMetry-Pro`**.
4. Готово! Приложение мгновенно начнет отображать показания со спутников, перегрузки и спидометр.

## 🚦 Светодиодная индикация (WS2812B)

- 🔴 **Плавная пульсация**: Поиск спутников GPS / Фикс еще не пойман.
- 🟢 **Постоянный зеленый**: **ARMED** (Прибор взведен, авто стоит неподвижно — жмите газ!).
- 🔵 **Пульсирующий циан**: Идет активный замер разгона.
- ❇️ **Тройная зеленая вспышка**: Заезд успешно завершен (уклон валиден).
- 🔶 **Тройная оранжевая вспышка**: Заезд завершен, но уклон превысил норму (> -1.0%).
- 🟣 **Фиолетовый стробоскоп**: Идет калибровка горизонта IMU.
